# Emotion Detection Application

An AI-based web application that detects and extracts emotions from text statements using Watson NLP and Python Flask.

## Project Name
AI-based Text Emotion Detector Web Application

## Features
- Detects subtle emotions: anger, disgust, fear, joy, and sadness.
- Identifies the dominant emotion with highest confidence score.
- Web deployment using Flask.
- Robust error handling for blank entries and invalid input.
- Fully unit-tested using Python unittest.
- Clean code rated 10.00/10 on static code analysis with PyLint.

## Installation and Execution
1. Clone the repository:
   ```bash
   git clone https://github.com/jaguar0005/oaqjp-final-project-emb-ai.git
   ```
2. Navigate to directory:
   ```bash
   cd oaqjp-final-project-emb-ai
   ```
3. Run the Flask server:
   ```bash
   python server.py
   ```
4. Access the web interface at `http://localhost:5000/`.
